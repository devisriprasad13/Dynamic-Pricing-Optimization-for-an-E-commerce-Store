💰 Dynamic Pricing Optimization for E-commerce Store

This project builds a **Dynamic Pricing Optimization System** that helps e-commerce businesses adjust product prices based on real data like demand, discount, and customer behavior — to **maximize revenue** intelligently.

📊 Project Overview

In competitive online markets, static prices can cause lost revenue or low sales.  
This system uses **machine learning regression models** to:
- Predict expected revenue or purchase likelihood.
- Suggest the **optimal price** for each product.
- Visualize revenue trends dynamically.

The project is also deployed as a **Streamlit Web App** for interactive analysis.

 🧩 Features

✅ Predicts **expected revenue** based on product & customer attributes  
✅ Suggests **optimal price** for maximum profit  
✅ Interactive **Streamlit dashboard**  
✅ Visual **Revenue vs Price curve**  
✅ Easy to extend to Power BI or Tableau
